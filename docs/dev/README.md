# Developer notes

Design records, contracts and phase hand-offs from building Migratarr. They
explain why the code is shaped the way it is and are kept for contributors;
none of them is needed to install or use Migratarr. User documentation is in
[`docs/`](..) and starts at the [README](../../README.md).

Some notes cite plans and reviews in the maintainer's private `reviews/`
folder; those references are records of where a decision was made, not links
to follow.
